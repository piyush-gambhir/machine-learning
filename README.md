# Machine Learning Projects

A collection of machine-learning practice projects spanning predictive modelling, computer vision, and NLP.

## Projects

- **California Housing Prices Prediction** — regression on the California housing dataset
- **Face Recognition — Yale Face Database** — face recognition using classical CV
- **Handwritten Digit Prediction (MNIST)** — digit classification baseline
- **IRIS Dataset** — multi-class classification on the Iris dataset
- **Loan Approval Prediction** — tabular classification on loan data

The `#/` directory holds additional smaller projects — Face Detection (OpenCV), Streamlit-based Medical Insurance Cost Predictor, Realtime Twitter Sentiment Analysis (NLP), Machine Learning with PySpark, Text Summarization, Speech-to-Text, Recommendation Engine on IMDB Movies, OCR Image-to-Text, Big Mart / Black Friday sales prediction, Türkiye Student Evaluation clustering, and others.

## Stack

Python, scikit-learn, pandas, NumPy, matplotlib, OpenCV, Streamlit, PySpark, NLTK.

## Running

```bash
cd "California Housing Prices Prediciton"
pip install -r requirements.txt   # if present
jupyter notebook
```
